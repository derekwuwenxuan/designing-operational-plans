# Designing Operational Plans

A reusable agent skill for turning notes, task lists, and shallow proposals into decision-ready, executable, measurable, and reviewable operational plans.

## Scope

The skill is industry-neutral. It supports campaigns, user operations, communities, memberships, content, growth, launches, partnerships, internal initiatives, and phased operating programs.

## Install

```bash
mkdir -p ~/.agents/skills/designing-operational-plans
cp SKILL.md ~/.agents/skills/designing-operational-plans/SKILL.md
```

## Files

- `SKILL.md` — the skill definition
- `tests/validate_skill.py` — static validation for naming, structure, required concepts, and domain isolation
